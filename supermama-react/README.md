# SuperMama Classroom — React + Vite JavaScript

This export uses JavaScript only (`.js` and `.jsx`). It contains no TypeScript source files.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The UI uses hash-based navigation, so it works on ordinary static hosting without server rewrite rules.

## Demo data

Login, purchase ownership, and lesson progress are stored in the browser's `localStorage`. Replace these demo handlers with your real authentication, payment webhook, entitlement, and progress APIs for production.
